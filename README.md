  ## About This Project

> Shift is a vehicle  simulator made in the Godot engine attempting to become the gold standard of vehicle simulation. This projects aims to simulate vehicles at an accurate level and was made as an alternative to other vehicle simulators open to anyone to improve, work on, use for projects, or personal use.

  ### Feature List
  > * 300 Hz Tick Rate Project
  > * 100+ of tuning parameters for ultimate control 
  > * Modular Functions for easy re-use
  > * Car
  >   * Brush Tire Model
  >   * Rigid Body Car
  >   * One Point Raycast Wheels
  > * Engine 
  >   * Curve Based Engine Torque Model
  >   * Dry Clutch Torque Model
  >   * Open Differential or LSD Simulation (Torsen, Clutch, Electronic)
  > * Brake
  > * Transmission
  >   * Manual
  >   * Customizable Gears and Gear Ratios
  > * Suspension 
  >   * Hz based Spring Force Model
  >   * Damper Ratio based Spring Damping Model
  >   * Anti-roll Bar Model
  > * Driver Assists 
  >   * Anti Lock Brake Simulation
  >   * Traction Control Simulation
  > * Steering 
  >   * Ackermann Steering Model
  >   * Adjustable Ackermann
  >   * Adjustable Steering Ratio and Angle
  > * Example Assets 
  >   * Roadster Example Car
  >   * E30 Example Car 
  >   * Track Example (Ichi Circuit) 

  ## Getting Started

  ### Installing Plugin

> Requirements: Hardware Supporting Godot 4.7
>
> 1. Download the latest project release
> ```
> https://github.com/kakoiihito/Shift/releases/download/v1.0.0/Shift-v1.0.zip)
> ```
> 2. Install and Open Godot Engine (https://godotengine.org/download/windows/)
> 3. Create or open an existing project

><img width="588" height="170" alt="plugin" src="https://github.com/user-attachments/assets/5665376d-4a65-42c7-9a63-c222e3270d22" />

> 4. Select the Import Button
> 5. Find the zip file and import it
> 6. Compile the project or run through the engine

  ### Using Source Code

> Requirements: Operating System and Hardware Supporting Godot 4.7 and git
>
> 1. Download the project using git
> ```
> gh repo clone kakoiihito/Shift
> ```

> 2. Install and Open Godot Engine (https://godotengine.org/download/windows/)
><img width="537" height="315" alt="image" src="https://github.com/user-attachments/assets/e2f77325-545f-43d4-9a64-a1d867b0a4e0" />

> 3. Select the Import button in the Project Manager window
> 4. Find the folder and import it
> 5. Compile the project or run through the engine

  ### Documentation
  
> Any code explanations, tuning advice, or project setup can be viewed in the Godot documentation system. Either press F1 and search the related class, hold Ctrl and click on the related class in the code, or hit the Search Help button near the play project button.
